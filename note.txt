// Nếu dùng 1 file index để hiển thị
- Lý do nên dùng chỉ 1 file hiển thị chính là index.php ở thư mục gốc:
    + Chỉ cần nhúng header tại 1 file duy nhất
    + Session_start ở ngay index hiển thị chính mà không cần cho từng view
    + Gọi Link đơn giản hơn 
    + Trỏ thẳng đến file, ít phải chỉnh sửa kiểu './' hoặc '../'
    + Có thể nhúng tất cả các file model,view,controller (1) ở tại index và gọi ở bất cứ chỗ nào trong các file khác
    + Có thể khai báo 1 loại đường dẫn để sử dụng cho mọi view được gọi.
- Link mặc định khi dùng hiển thị 1 file index: index.php?{biến để get}={giá trị}&{biến thứ 2}={giá trị thứ 2}...
- Có thể thay thế '<?php echo ?>' bằng '<?= ?>'

// Nếu gọi từng view để hiển thị
- Phải chỉnh chính xác các đường dẫn để không bị lỗi khi gọi hàm ở view.
- Chú ý kỹ đường dẫn từ file này đến file khác
- Mỗi view đều phải có header và footer riêng, js, css
- Khi gọi view ra phải get đúng tham số được truyền vào
- Xem kỹ các đường dẫn có trỏ đúng hay chưa
